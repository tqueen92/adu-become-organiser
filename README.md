# ADU – Become an Organiser

A one-page guide for people who want to become a Panel & Talk Organiser at Amsterdam Data Union (ADU). It explains the role, the time it takes and how the selection works, then links to the application form (Google Form).

**Live page:** https://tqueen92.github.io/adu-become-organiser/

## How to update the text

Everything is in `index.html`. No build step needed.

1. Open `index.html` on GitHub and click the ✏️ pencil icon.
2. Find the text you want to change. Each part of the page is a `<section>` with a clear id: `about`, `role`, `time`, `how`, `why`, `apply`.
3. Click **Commit changes**.

To change the form link, search for `docs.google.com/forms` and replace the link.

The "Why we ask these questions" text is also in the Google Form. If you change it here, change it there too.

GitHub Pages publishes the change in 1 to 5 minutes. Use **Cmd + Shift + R** (Mac) or **Ctrl + Shift + R** (Windows) to reload without the old cached version.
